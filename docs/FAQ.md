# 版本与常见问题

## 与英文出版版完全一致吗？

不能保证。本仓库是 Nathan Lambert 开源 RLHF Book 的中文翻译，包含 19 章；`metadata.yml` 的日期为 2025-04-16，但它不能代替上游 commit 或出版版版本号。目前没有完整的逐章对照记录。

如需对照，请在 Issue 中提供英文版的版本、章节、小节或公开链接。后续应逐章记录上游 commit、译文修订和差异，避免用「最新」「完全一致」描述未经核实的状态。

## Markdown、PDF 与 Release 为什么不同？

源文件修改不会自动替换仓库中的 PDF 或历史 Release。2026-09-20 检查时，`v1.0` 仅发布 `book.pdf`。源文件包含后续修复；本地构建可获得当前源文件对应的产物。引用或报告问题时请说明使用哪一种版本。

## 有在线阅读、EPUB 或训练代码吗？

仓库提供 HTML、EPUB、PDF、DOCX 的构建入口。在线阅读地址和下载附件应以实际验证的发布结果为准，不把构建能力等同于已经发布。章节中的算法示例用于讲解，仓库不是完整的分布式训练工程。

## GitHub 上看到 `[@...]` 是错误吗？

这些是 Pandoc 的文献或交叉引用语法，需要构建后才能完整显示。已生成的 HTML、EPUB 或 PDF 中若仍有无法解析的引用，请报告具体位置。

## 不会写代码也能贡献吗？

可以。欢迎提出术语、句子、公式和阅读体验问题；通过 GitHub 的编辑按钮也能提交文字纠错。见 [贡献指南](../CONTRIBUTING.md)。
